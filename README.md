# My Vocab

Live site: **https://sda2025-tech.github.io/vocab/**

Advanced academic English in the same shape as [Mana Telugu](https://sda2025-tech.github.io/mana-telugu/): a daily lesson, then a book of practice, with the Instagram card generated from that day’s word.

- **Today** — one GRE-level word; learn, find, use; then stop
- **Lexicon** — 70 high-register words by cluster
- **Flashcards** — flip, hear, mark known
- **Text completion** — 1–2 blank GRE-style items
- **Sentence equivalence** — pick two synonyms that both fit
- **Instagram card** — download + caption from the same daily word
